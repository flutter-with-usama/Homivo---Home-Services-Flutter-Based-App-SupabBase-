# Homivo – Home Service Application

Homivo is a Flutter-based home service application designed to connect customers with reliable service providers for household needs, including plumbing, electrical work, and carpentry. The application aims to simplify service discovery, appointment booking, and service request management through a user-friendly mobile interface.

### Key Features
- **Authentication:** Customer and service provider registration and login.
- **Service Discovery:** Browse available household services.
- **Service Booking:** Request and manage service appointments.
- **Provider Dashboard:** Accept or reject customer service requests.
- **Provider Profiles:** Showcase skills, experience, and service charges.
- **Ratings and Reviews:** Collect customer feedback.
- **Payment Management:** Support the service payment workflow.
- **Admin Management:** Provider verification, user management, and complaint handling.

### Technology Stack
- Flutter and Dart
- Supabase for backend and database services
- SharedPreferences for local data storage
- MVVM architecture with ChangeNotifier and repositories
- Material Design and Poppins typography

### Objective
Homivo aims to make home-service booking more convenient by providing a centralized platform for customers, service providers, and administrators.
