# Homivo

A home services booking app built with Flutter.

Homivo connects clients with verified service providers for plumbing, electrical,
cleaning, carpentry, painting, and more — all from one app.

## Getting Started

This project is built with Flutter. To run it locally:

```bash
flutter pub get
flutter run
```

For help getting started with Flutter development, view the
[online documentation](https://docs.flutter.dev/).
